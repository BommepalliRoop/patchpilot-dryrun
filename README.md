## How we work on the day
1. Open the repo in Claude Code.
2. Pick your lane in `tasks/BOARD.md`.
3. Switch to the model listed for the task (`/model`), then run `/run-task T0X`.
4. When Claude finishes, it prints the next tasks you can start. Run `/next-task` any time.
