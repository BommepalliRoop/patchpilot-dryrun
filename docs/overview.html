PatchPilot · team briefing

From code link to fixed code, in 8 steps

Companies get hundreds of security warnings about the libraries their code uses. Most don't matter. PatchPilot finds the few that really matter, fixes them, tests the fix, and tells the right people. Automatically, every day.

Our main requirement
InputA link to a GitHub code repository. Any language.
OutputA tested fix waiting for approval, a Jira ticket, a Slack message and an audit record.
PeopleNo one has to do anything in between.

Each step in plain words

1
Team member in the web app · or Boomi, every morning

Give PatchPilot the code link

Open the PatchPilot web app, click Run scan and paste the GitHub link. Public repos work straight away. Private repos need a one-time access key from GitHub, set up once by the team lead. Boomi can also start this every day at 9:00 on its own.

PatchPilot

Read the ingredients list

Every project has a file that lists the outside libraries it uses, with exact versions. PatchPilot finds these files and works out the languages by itself, so nobody has to tell it.

PatchPilot

Look up known security problems

Each library version is checked against a free public database of known security holes (OSV, run by Google). It also checks a government list of holes that attackers are using right now.

About 35 warnings on our demo project

4
PatchPilot + AI

Keep only the warnings that matter

A warning only matters if our code actually uses the broken part of the library. PatchPilot reads the code, finds the exact line that uses it, and AI double-checks. This is what turns a long list into a short one.

Rank by real risk

Each real problem gets a score from how serious it is, whether outsiders can reach it through the website, and whether attackers are using it. Then it gets a priority.

PatchPilot + AI

Fix it and prove the fix works

PatchPilot moves the library to the nearest safe version and runs the project's own tests in a safe sandbox. If something breaks, AI makes a small repair and tests again, up to two times. If it still fails, a person takes over.

7
PatchPilot + Boomi

Hand it to the right people

The fix arrives as a pull request that the client's developers approve. It is never merged on its own. Boomi then creates a Jira ticket, posts a Slack message and saves an audit record for security reviews.
